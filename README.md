# 3-body-problem-simulation-in-2D
I made a programm that can simulate the 3 body problem in the 2D plane. One can set between 3 approximation methods (Euler, better Euler, Runge-Kutta) to compare them. 
This project was a homework during my computational physics course at RWTH- Aachen university.
